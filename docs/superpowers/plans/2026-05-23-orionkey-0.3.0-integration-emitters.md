# OrionKey 0.3.0 — Integration Emitters Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add four conditional integration emitters (Dapper, Newtonsoft.Json, MongoDB driver, Swashbuckle/OpenAPI) plus per-library aggregate registrars, shipping as `0.3.0`.

**Architecture:** Each new emitter mirrors `EfCoreConverterEmitter` — a probe in `OrionIdGenerator.Initialize` checks the consumer's compilation for an anchor type from the target package; if present, the emitter runs and adds a `.g.cs` companion. The existing `efCoreReferenced` flag is replaced by an `IntegrationFlags` record carrying all five integration-presence booleans. A second pipeline collects every parsed `OrionIdModel` per compilation and emits a single aggregate `OrionKey<Library>Registrar` static class per active integration, so users wire up everything with one call at startup.

**Tech Stack:** C# 13, .NET 8/9/10 multi-target, Roslyn incremental source generator (netstandard2.0), xUnit, BenchmarkDotNet. New package references: Dapper 2.1.35, Newtonsoft.Json 13.0.3, MongoDB.Driver 3.0.0, Swashbuckle.AspNetCore 7.0.0.

## Background for the implementer

OrionKey 0.2 already generates `System.Text.Json` converter, BCL `TypeConverter`, `IParsable`/`ISpanParsable`, `IComparable`, and a conditional EF Core `ValueConverter`. The pattern this phase extends is exactly the EF Core one:

1. `OrionIdGenerator.Initialize` checks `compilation.GetTypeByMetadataName("Microsoft.EntityFrameworkCore.Storage.ValueConversion.ValueConverter\`2")`.
2. The result is combined with each parsed symbol via `RegisterSourceOutput`.
3. `Handle` calls `EfCoreConverterEmitter.Emit(model)` only when the flag is true.

Phase B repeats that for four more libraries, then adds one new pipeline (`Collect()`-based) to emit the aggregate registrars.

**Key facts:**

- Runtime project `src/Moongazing.OrionKey/` multi-targets `net8.0;net9.0;net10.0`. `TreatWarningsAsErrors` is on.
- Generator project `src/Moongazing.OrionKey.Generators/` targets `netstandard2.0` (Roslyn requirement).
- Generated code lands in the consumer's assembly, so it can freely reference Dapper/Newtonsoft/Mongo/Swashbuckle types when those packages are present.
- `tests/Moongazing.OrionKey.Generators.Tests/GeneratorHarness.cs` builds the test compilation from `AppDomain.CurrentDomain.GetAssemblies()` after force-loading the runtime and EF Core. Adding new package references to the test project will make them visible to the harness automatically (positive-emission tests). The harness needs a small extension to support "without this assembly" negative tests (Task 2).
- The `OrionIdGenerator.Initialize` pipeline currently registers two `RegisterSourceOutput` calls — one per attribute arity, each combined with `efCoreReferenced`. Phase B replaces those with `IntegrationFlags` and adds a third pipeline (`Collect()` over both arities) for the aggregate registrars.

**Files:**

The harness currently builds the test compilation from every loaded assembly. To prove that an emitter does *not* fire when its anchor package is absent, we need a way to exclude specific assemblies from the reference set. Existing positive tests stay on the zero-arg `Run(source)` overload.

- [ ] **Step 1: Add the overload**

Replace the existing `GeneratorHarness` class body in `tests/Moongazing.OrionKey.Generators.Tests/GeneratorHarness.cs` with:

```csharp
using System.Collections.Generic;
using System.Linq;
using Microsoft.CodeAnalysis;
using Microsoft.CodeAnalysis.CSharp;
using Moongazing.OrionKey.Generators;

namespace Moongazing.OrionKey.Generators.Tests;

/// <summary>Runs OrionIdGenerator against a source string and exposes the result.</summary>
internal static class GeneratorHarness
{
    public static GeneratorRunResult Run(string source)
        => Run(source, excludeAssemblyNamePrefixes: System.Array.Empty<string>());

    /// <summary>
    /// Runs the generator with the given source while excluding any assembly whose simple
    /// name starts with one of the supplied prefixes. Use this for negative-emission tests
    /// that assert "without package X referenced, emitter Y produces nothing".
    /// </summary>
    public static GeneratorRunResult Run(string source, params string[] excludeAssemblyNamePrefixes)
    {
        var syntaxTree = CSharpSyntaxTree.ParseText(source);

        // Force the runtime assembly to load so its metadata is available as a reference.
        _ = typeof(global::Moongazing.OrionKey.OrionIdAttribute<>).Assembly;

        // Force the EF Core assembly to load so the conditional ValueConverter emitter
        // sees Microsoft.EntityFrameworkCore as a referenced assembly.
        _ = typeof(global::Microsoft.EntityFrameworkCore.Storage.ValueConversion.ValueConverter<,>).Assembly;

        IEnumerable<System.Reflection.Assembly> assemblies = System.AppDomain.CurrentDomain.GetAssemblies()
            .Where(a => !a.IsDynamic && !string.IsNullOrEmpty(a.Location));

        if (excludeAssemblyNamePrefixes.Length > 0)
        {
            assemblies = assemblies.Where(a =>
            {
                var name = a.GetName().Name ?? string.Empty;
                return !excludeAssemblyNamePrefixes.Any(prefix =>
                    name.StartsWith(prefix, System.StringComparison.Ordinal));
            });
        }

        var references = assemblies
            .Select(a => MetadataReference.CreateFromFile(a.Location))
            .Cast<MetadataReference>()
            .ToList();

        var compilation = CSharpCompilation.Create(
            "GeneratorTestAssembly",
            new[] { syntaxTree },
            references,
            new CSharpCompilationOptions(OutputKind.DynamicallyLinkedLibrary));

        var driver = CSharpGeneratorDriver
            .Create(new OrionIdGenerator())
            .RunGenerators(compilation);

        return driver.GetRunResult().Results.Single();
    }

    /// <summary>Concatenates every generated source for substring assertions.</summary>
    public static string AllGeneratedText(this GeneratorRunResult result)
        => string.Join("\n\n", result.GeneratedSources.Select(s => s.SourceText.ToString()));
}
```

```csharp
using Microsoft.CodeAnalysis;
using Moongazing.OrionKey.Generators.Parsing;

namespace Moongazing.OrionKey.Generators;

/// <summary>
/// Incremental generator that turns <c>[OrionId]</c>-decorated structs into fully-featured
/// strongly-typed ids.
/// </summary>
[Generator(LanguageNames.CSharp)]
public sealed class OrionIdGenerator : IIncrementalGenerator
{
    private const string OneArgAttribute = "Moongazing.OrionKey.OrionIdAttribute`1";
    private const string TwoArgAttribute = "Moongazing.OrionKey.OrionIdAttribute`2";

    public void Initialize(IncrementalGeneratorInitializationContext context)
    {
        var oneArg = context.SyntaxProvider.ForAttributeWithMetadataName(
            OneArgAttribute,
            predicate: static (_, _) => true,
            transform: static (ctx, _) => ctx.TargetSymbol as INamedTypeSymbol);

        var twoArg = context.SyntaxProvider.ForAttributeWithMetadataName(
            TwoArgAttribute,
            predicate: static (_, _) => true,
            transform: static (ctx, _) => ctx.TargetSymbol as INamedTypeSymbol);

        var flags = context.CompilationProvider.Select(static (compilation, _) => new IntegrationFlags(
            HasEfCore: compilation.GetTypeByMetadataName(
                "Microsoft.EntityFrameworkCore.Storage.ValueConversion.ValueConverter`2") is not null,
            HasDapper: compilation.GetTypeByMetadataName(
                "Dapper.SqlMapper+TypeHandler`1") is not null,
            HasNewtonsoftJson: compilation.GetTypeByMetadataName(
                "Newtonsoft.Json.JsonConverter") is not null,
            HasMongo: compilation.GetTypeByMetadataName(
                "MongoDB.Bson.Serialization.Serializers.SerializerBase`1") is not null,
            HasSwashbuckle: compilation.GetTypeByMetadataName(
                "Swashbuckle.AspNetCore.SwaggerGen.ISchemaFilter") is not null));

        context.RegisterSourceOutput(oneArg.Combine(flags),
            static (spc, pair) => Handle(spc, pair.Left, pair.Right));
        context.RegisterSourceOutput(twoArg.Combine(flags),
            static (spc, pair) => Handle(spc, pair.Left, pair.Right));
    }

    private static void Handle(SourceProductionContext spc, INamedTypeSymbol? symbol, IntegrationFlags flags)
    {
        if (symbol is null)
        {
            return;
        }

        if (!OrionIdParser.TryParse(symbol, out var model, out var diagnostics))
        {
            foreach (var diagnostic in diagnostics)
            {
                spc.ReportDiagnostic(diagnostic);
            }
            return;
        }

        foreach (var diagnostic in diagnostics)
        {
            spc.ReportDiagnostic(diagnostic);
        }

        spc.AddSource($"{model!.Name}.OrionId.g.cs", Emit.CoreBodyEmitter.Emit(model));

        var comparable = Emit.ComparableEmitter.Emit(model);
        if (comparable is not null)
        {
            spc.AddSource($"{model.Name}.OrionId.Comparable.g.cs", comparable);
        }

        spc.AddSource($"{model.Name}.OrionId.Json.g.cs", Emit.JsonConverterEmitter.Emit(model));
        spc.AddSource($"{model.Name}.OrionId.TypeConverter.g.cs", Emit.TypeConverterEmitter.Emit(model));
        spc.AddSource($"{model.Name}.OrionId.Parsable.g.cs", Emit.ParsableEmitter.Emit(model));

        if (flags.HasEfCore)
        {
            spc.AddSource($"{model.Name}.OrionId.EfCore.g.cs", Emit.EfCoreConverterEmitter.Emit(model));
        }
    }
}
```

This is the existing pipeline with `bool efCoreReferenced` replaced by `IntegrationFlags flags`. New emitters in later tasks add their own `if (flags.HasX) spc.AddSource(...)` blocks here.

using System.Text;
using Moongazing.OrionKey.Generators.Model;
using ValueType = Moongazing.OrionKey.Generators.Model.ValueType;

namespace Moongazing.OrionKey.Generators.Emit;

/// <summary>Emits a Dapper SqlMapper.TypeHandler. Only invoked when Dapper is referenced.</summary>
internal static class DapperTypeHandlerEmitter
{
    public static string Emit(OrionIdModel model)
    {
        var name = model.Name;
        var handler = $"{name}DapperTypeHandler";

        var dbType = model.ValueType switch
        {
            ValueType.Guid => "global::System.Data.DbType.Guid",
            ValueType.Int32 => "global::System.Data.DbType.Int32",
            ValueType.Int64 => "global::System.Data.DbType.Int64",
            ValueType.String => "global::System.Data.DbType.String",
            _ => throw new System.ArgumentOutOfRangeException(nameof(model)),
        };

        var parseExpr = model.ValueType switch
        {
            ValueType.Guid =>
                $"value is global::System.Guid g ? new {name}(g) "
                + $": new {name}(global::System.Guid.Parse((string)value!))",
            ValueType.Int32 =>
                $"new {name}(global::System.Convert.ToInt32(value, "
                + "global::System.Globalization.CultureInfo.InvariantCulture))",
            ValueType.Int64 =>
                $"new {name}(global::System.Convert.ToInt64(value, "
                + "global::System.Globalization.CultureInfo.InvariantCulture))",
            ValueType.String => $"new {name}((string)value!)",
            _ => throw new System.ArgumentOutOfRangeException(nameof(model)),
        };

        var sb = new StringBuilder();
        sb.AppendLine("// <auto-generated/>");
        sb.AppendLine("#nullable enable");
        if (model.Namespace.Length != 0)
        {
            sb.AppendLine($"namespace {model.Namespace};");
            sb.AppendLine();
        }
        sb.AppendLine($"/// <summary>Dapper type handler for <see cref=\"{name}\"/>.</summary>");
        sb.AppendLine($"public sealed class {handler} "
                    + $": global::Dapper.SqlMapper.TypeHandler<{name}>");
        sb.AppendLine("{");
        sb.AppendLine($"    public override {name} Parse(object value) => {parseExpr};");
        sb.AppendLine($"    public override void SetValue("
                    + $"global::System.Data.IDbDataParameter parameter, {name} value)");
        sb.AppendLine("    {");
        sb.AppendLine($"        parameter.DbType = {dbType};");
        sb.AppendLine("        parameter.Value = value.Value;");
        sb.AppendLine("    }");
        sb.AppendLine("}");
        return sb.ToString();
    }
}
```

            signature: "Register()",
            body: BuildStatements(models, m =>
                $"global::Dapper.SqlMapper.AddTypeHandler(new {Qualify(m)}DapperTypeHandler());"));

    public static string EmitNewtonsoftJson(IReadOnlyList<OrionIdModel> models)
        => EmitRegistrar(
            className: "OrionKeyNewtonsoftJsonRegistrar",
            summary: "Adds every generated Newtonsoft.Json converter to the supplied settings.",
            signature: "AddTo(global::Newtonsoft.Json.JsonSerializerSettings settings)",
            body: BuildStatements(models, m =>
                $"settings.Converters.Add(new {Qualify(m)}NewtonsoftJsonConverter());"));

    public static string EmitMongo(IReadOnlyList<OrionIdModel> models)
        => EmitRegistrar(
            className: "OrionKeyMongoRegistrar",
            summary: "Registers every generated MongoDB BSON serializer with BsonSerializer.",
            signature: "Register()",
            body: BuildStatements(models, m =>
                "global::MongoDB.Bson.Serialization.BsonSerializer.RegisterSerializer("
                + $"typeof({Qualify(m)}), new {Qualify(m)}BsonSerializer());"));

    public static string EmitOpenApi(IReadOnlyList<OrionIdModel> models)
        => EmitRegistrar(
            className: "OrionKeyOpenApiRegistrar",
            summary: "Adds every generated Swashbuckle schema filter to the supplied options.",
            signature: "AddTo(global::Swashbuckle.AspNetCore.SwaggerGen.SwaggerGenOptions options)",
            body: BuildStatements(models, m =>
                $"options.SchemaFilter<{Qualify(m)}SchemaFilter>();"));

    private static string Qualify(OrionIdModel model)
        => model.Namespace.Length == 0
            ? $"global::{model.Name}"
            : $"global::{model.Namespace}.{model.Name}";

    private static string BuildStatements(
        IReadOnlyList<OrionIdModel> models,
        System.Func<OrionIdModel, string> render)
    {
        var sb = new StringBuilder();
        foreach (var model in models)
        {
            sb.Append("        ");
            sb.AppendLine(render(model));
        }
        return sb.ToString();
    }

    private static string EmitRegistrar(string className, string summary, string signature, string body)
    {
        var sb = new StringBuilder();
        sb.AppendLine("// <auto-generated/>");
        sb.AppendLine("#nullable enable");
        sb.AppendLine();
        sb.AppendLine($"/// <summary>{summary}</summary>");
        sb.AppendLine($"public static class {className}");
        sb.AppendLine("{");
        sb.AppendLine($"    public static void {signature}");
        sb.AppendLine("    {");
        sb.Append(body);
        sb.AppendLine("    }");
        sb.AppendLine("}");
        return sb.ToString();
    }
}
```
